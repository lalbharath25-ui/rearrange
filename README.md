# Rearrange

Pick two pictures. Every pixel of the first is moved — none added, none recoloured — until together they rebuild the second.

**Live:** https://lalbharath25-ui.github.io/rearrange/

- Runs entirely in the browser; images are never uploaded.
- Opens JPG, PNG, WebP, GIF, HEIC, AVIF, TIFF, BMP, SVG, PSD, JPEG XL, camera RAW, TGA, QOI, HDR and more.
- Static site: `index.html` (page), `engine.js` (pixel assignment), `formats.js` (image decoding), `target.js` (default target picture).
